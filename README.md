# Traffic Data Analysis Using Python

## Overview
This project demonstrates basic traffic data analysis using Python. It reads hourly traffic count data from a CSV file, calculates traffic statistics, identifies the peak traffic hour, visualizes traffic volume, and exports the processed data to Excel.

## Features
- Read traffic count data from a CSV file
- Calculate total hourly traffic
- Identify the peak traffic hour
- Calculate maximum, minimum, and average traffic
- Generate a traffic volume graph
- Export results to an Excel file

## Technologies Used
- Python
- Pandas
- Matplotlib
- OpenPyXL
